# Прибрані з інтерфейсу можливості

Ці елементи колись були в бібліотеці, але зараз вимкнені. Код і стилі **збережено в Git** — нічого не загублено.

## Що прибрано (листопад 2026)

| Що | Де було |
| --- | --- |
| **«Знайдені історії в чаті»** — блок з картками історій з останньої відповіді, лічильник і підпис «За запитом «…»» | Права панель, під меню бібліотеки |
| **«Історії за темами»** — розділ меню з темами (Евакуація та дорога, Побут і виживання тощо), екран теми з описом і кнопкою «Запитати про тему в чаті» | Меню бібліотеки та згорнута смужка |
| **«Усі теми»** — випадаючий фільтр за темою | У списку «Усі історії», праворуч від перемикача типу |

Самі дані тем (`RUBRICS` у `src/data.ts`) лишилися, тож відновлення не потребує нових даних.

## Де збережено

Тег **`archive/topics-and-found-stories`** (коміт `9e8f2b9`) — останній стан, у якому все це ще працювало. Тег є і на GitHub.

## Як подивитися

```bash
git show archive/topics-and-found-stories:src/pages/LibPanel.tsx
```

## Як повернути

Перегляньте різницю між тегом і поточним станом, потім перенесіть потрібні частини (зазвичай це `src/pages/LibPanel.tsx`, `src/pages/Search.tsx` та стилі `src/styles/components/chat-layout.css`):

```bash
git diff archive/topics-and-found-stories -- src/pages/LibPanel.tsx src/pages/Search.tsx src/styles/components/chat-layout.css
```

Або створіть гілку від тегу й порівняйте в зручному редакторі:

```bash
git switch -c restore-topics archive/topics-and-found-stories
```
